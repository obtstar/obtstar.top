快速开始

环境初始化（两阶段）→ 构建 → 运行 → 常用命令

环境初始化（两阶段）

阶段一（root）：用户、目录、克隆 control-center

curl -fsSL https://gh.dpik.top/https://raw.githubusercontent.com/obtstar/control-center/dev/scripts/init-env.sh -o /tmp/init-env.sh
sudo bash /tmp/init-env.sh --

阶段二（dev 身份）：工具链、同步、PieKBS

bash ~/control-center/scripts/setup-env.sh [--executor|--check|--skip-*]

构建

# control-api（Go）
cd ~/control-api && go build ./...

# control-piekbs（必须带 fts5 tag）
cd ~/control-piekbs && go build -tags fts5 ./...

# control-web（React）
cd ~/control-web && pnpm build

运行（systemd 用户服务）

服务端口说明
piekbs-mcp8766KB FTS 检索 / MCP
control-api8765任务状态机 / 审批 / 审计 / SSE
dsh-web3080DSH AI 会话（模型出口）
control-web4173审批工作台（与 dsh 同步启动）

常用命令

# 测试
cd ~/control-api && go test ./...
cd ~/control-piekbs && go test -tags fts5 ./...
cd ~/control-web && pnpm test

# 对账（文档声明 ↔ 代码事实）
~/control-api/control-api reconcile

# 用户管理
~/control-api/control-api user add <username> <role>

环境检查

bash ~/control-center/scripts/setup-env.sh --check
