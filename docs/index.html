平台定位

control 是面向内网部署的单人 AI Agent 平台：Agent 在会话内执行任务流水线 （requirements → design → coding → testing → merge → deliver），每一阶段产物经 审批闸由人批准后才进入下一阶段——AI 干活，人审批，最终合并权始终在人。

核心原则

AI 驱动执行，用户逐步审批

流水线每阶段一道审批闸，用户保留最终合并权；驳回附批注，AI 带批注返工。

权柄分级，有据可依

文档按 L1 需求 → L2 概要 → L3 详细 → L4 代码分级；AI 顺行产出，禁止逆行修改上级文档；产出引用 KB 依据。

Git 为唯一可信源

代码、文档、编排配置、注册表、任务、KB 全进 Git；任务即文档（task.md 权威）。

数据内网，AI 外接受控

模型请求经 DSH 统一出口；代码/数据不出本机；密钥不落盘，操作全留痕（work_log hash 链）。

C1 执行模型

任务阶段由 DSH 会话执行（模型接入 DSH），阶段产物落任务目录后经 advance 回传进入审批闸；人工在 control-web 工作台审批。 模型出口收敛为 DSH 单一通道（LiteLLM 网关已砍除）。
