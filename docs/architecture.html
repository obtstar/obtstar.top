control 介绍 架构 快速开始 平台状态

平台架构

多仓（multi-repo）本地开发环境：平台六仓 + 业务项目仓按需登记

平台六仓

仓库角色说明
control-center引导仓编排配置 orchestration/、注册表 registry/、环境脚本 scripts/
control-api编排后端Go HTTP 服务：任务状态机、审批、审计、契约对账、SSE 事件流
control-web工作台前端React 审批工作台：看板/审批/审计/KB/API 文档/AI 助手
control-piekbs知识引擎Go 编写：FTS 搜索 + MCP 服务 + 文档蒸馏（wiki-distill 技能）
control-db数据库 DDLSQLite 运行时库 DDL（当前占位）
control-wiki平台级 KBraw/ 原始文档、wiki/ 蒸馏产物、schema/ 规则

技术栈

后端

Go 1.25+ · stdlib net/http mux（无 Web 框架）· SQLite（WAL）

前端

React 18 · PrimeReact · Vite · pnpm（审批工作台）

AI 执行

DSH 会话（dsh-llm 统一出口）· control 插件工具桥（14 个 control_* 工具）

知识

PieKBS FTS 检索 · wiki-distill 蒸馏 · KB grounding 有据校验

流水线（每阶段一审批闸）

requirements → design → coding → testing → merge → deliver
      ↑ 审批闸    ↑ 审批闸    ↑ 审批闸   ↑ 审批闸    ↑ 团队 MR 终审
